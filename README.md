# libfprint driver for the EgisTec EH57A (`1c7a:057a`)

A native Linux [libfprint](https://gitlab.freedesktop.org/libfprint/libfprint)
driver for the **LighTuning Technology Inc. EgisTec EH57A** fingerprint reader
(USB ID `1c7a:057a`), so that it works with `fprintd`: enrolment, and fingerprint
login / `sudo` / screen unlock through PAM on stock GNOME/KDE.

> This project stands on the shoulders of
> [**PHILIPPDEV5396/libfprint-egis0576**](https://github.com/PHILIPPDEV5396/libfprint-egis0576)
> by Philipp Oster and its contributors, which brought the neighbouring EgisTec
> EH576 to libfprint. The driver structure, the USB transport, the
> suspend/resume handling and the systemd integration here come from that work.
> See [Credits](#credits) and [`PROVENANCE.md`](PROVENANCE.md).

## The sensor, briefly

Unlike the EH576, the EH57A is a **match-on-chip** sensor: fingerprints are
enrolled, stored and matched inside the chip. The host drives it with a command
set and receives a template id and a match verdict:

- **Transport** — `EGIS` + command on bulk EP `0x01`; `SIGE` replies on EP `0x82`.
  A command is wrapped in an APDU (`EGIS a0`) and its answer polled (`EGIS a1`).
- **Framing** — `55 AA 00 <cmd> <sub> 00 <len16> <payload>` plus a reflected
  CRC-16-CCITT.
- **Session** — an ECDH P-256 handshake with an SP800-108 HMAC-SHA256 KDF
  authenticates the host and yields the key that derives the 32-byte template id
  of an enrolment. libfprint stores only that id in the print.

See [`docs/protocol.md`](docs/protocol.md) for the command list.

## Install

Build requirements (Fedora names; Debian/Arch equivalents work the same):

```bash
sudo dnf install git meson ninja-build gcc pkgconf-pkg-config \
    glib2-devel libgusb-devel openssl-devel gobject-introspection-devel \
    libgudev-devel nss-devel pixman-devel cairo-devel systemd-devel gtk-doc
```

Then:

```bash
./install.sh                 # installs to /usr/local
PREFIX=/usr ./install.sh     # replace the distro's libfprint (Fedora: /usr/lib64)
```

The script clones libfprint `1.94.100`, copies [`driver/`](driver/) into it,
applies [`patches/libfprint-1.94.100-egis057a.patch`](patches/libfprint-1.94.100-egis057a.patch),
builds with the full default driver set (your other readers keep working) and
installs it, plus the [suspend/resume helpers](integration/README.md).

A libfprint driver is compiled into `libfprint-2.so`, so this replaces the
distro's `libfprint`; the stock `fprintd` loads it unchanged. A distro update of
`libfprint` will overwrite it — re-run the installer afterwards.

### Use it

```bash
sudo systemctl restart fprintd
fprintd-list "$USER"        # should show: LighTuning Technology Inc. EgisTec EH57A
fprintd-enroll
fprintd-verify
```

Enable fingerprint login in GNOME Settings → Users, or with
`sudo authselect enable-feature with-fingerprint` on Fedora.
